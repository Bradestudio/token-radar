Token Radar ranks 198 pre-token protocols by implied launch value, scored from the DeFiLlama snapshot's own numbers — TVL, 7-day growth and age without a token — against the multiples that live tokens in the same category actually trade at. It ships a sortable dashboard with a detail view and a concrete farm plan (steps, capital, gas, time) for every protocol on the board.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
